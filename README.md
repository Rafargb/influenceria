# Clone do Quiz Interativo Prettycat AI

Este projeto é um clone completo e autônomo do funil interativo/quiz da Prettycat AI.

## ⚙️ Configurações Atuais
- **UTMify Integrado:** Scripts de UTMs e Pixel do UTMify adicionados na tag `<head>`.
- **Checkout Greenn:** Configurado com a oferta de **R$ 22,30** nos botões de compra.
- **Preços Atualizados:** Todas as telas de oferta e resumo exibem o valor de **R$ 22,30**.
- **Meta Pixel antigo:** Removido.
- **Logo inicial:** Removida do cabeçalho.

## 📁 Estrutura de Arquivos
- `index.html`: Arquivo principal da página.
- 30 arquivos de mídia locais (imagens, fotos e vídeos mp4).

## 🚀 Como Executar
```bash
open /Users/apple/.gemini/antigravity/scratch/prettycat-quiz-clone/index.html
```
Ou pelo servidor local:
```bash
cd /Users/apple/.gemini/antigravity/scratch/prettycat-quiz-clone
python3 -m http.server 8080
```
Acesse: `http://localhost:8080`
